# Начальные данные портала

Начальные данные подготовлены по материалам ДЗ04 и загружаются Django-фикстурой.
[initial_data.json](../app/knowledge/fixtures/initial_data.json) находится
в собственном репозитории и содержит шесть статей о ДЗ01–ДЗ06.

При deploy миграции Django создают схему в PostgreSQL-кластере через HAProxy.
Команда `load_initial_data` вызывает `loaddata` для пустой БД и сохраняет
отметку о загрузке. Повторный deploy не перезаписывает пользовательские данные
и не восстанавливает удалённые пользователем материалы.

`seed_lessons` — совместимое имя той же команды начальной загрузки:
она читает готовую фикстуру из репозитория. Фикстура не содержит пользователей,
паролей или персональных данных; служебные таблицы и права создаёт Django.

Начальный набор не требует изображений. Существующий каталог media сохраняется;
при переносе данных с изображениями файлы media переносятся отдельно от БД.
Контрольные статьи проверок сохраняются как черновики и не видны на портале.

Проверки загрузки и сохранности данных приведены в [результатах](testing.md).
